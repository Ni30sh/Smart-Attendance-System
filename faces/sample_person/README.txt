This is a sample directory for demonstration purposes.

To add a real person:
1. Replace this directory name with the person's actual name
2. Add 3-5 clear face images (JPG or PNG format)
3. Restart the face recognition service

The images should be:
- Well-lit and clear
- Front-facing photos
- Different angles/expressions for better recognition
- Resolution between 200x200 to 1000x1000 pixels
